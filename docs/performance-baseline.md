## 测试平台

- 两台 R9000 相互桥接（一台中心基站，一台桥接模式当无线网卡）
- 测试机 i7-4770K / 8GB；工作机 i5-3570 / 8GB；笔记本 ASUS S300CA（Intel AC7260）
- 工具：IxChariot 6.7 + EndPoint 7.3、CrystalDiskMark、Wirelessmon

## 性能基线数据

| 项目 | 实测数据 |
|---|---|
| 2.4GHz 吞吐 | 约 290 Mbps（强干扰环境） |
| 5GHz 吞吐（4×4 桥接，80MHz） | 下行 ~900 Mbps / 上行 >850 Mbps / 双向均值 ~860 Mbps |
| 60GHz 吞吐 | 千兆级（测试设备无法组万兆，未发挥 4.6 Gbps） |
| LAN 吞吐 | 单向 ~940 Mbps / 双向 ~1700 Mbps |
| NAT（LAN→WAN） | ~940 Mbps（硬件加速） |
| USB 3.0 | 写 >60 MB/s / 读 >100 MB/s（PC 端参照 256/243 MB/s） |
| 覆盖 | 2.4G 覆盖除最远 F 点外全部；5G 在隔墙 C/D/E 点偏弱；半径 10m+ |

## 本机实测对照

| 项目 | 文章基线 | 本机实测 | 差异说明 |
|---|---|---|---|
| 5G | 4×4 80MHz ~860 Mbps | 2×2 40MHz rx 216~300 / tx 180 Mbps | 链3/4 硬件异常 → 只能 2×2；且当前 40MHz |
| 2.4G | ~290 Mbps | 未测 | — |
| LAN / NAT | ~940 Mbps | 未测 | — |
| USB 3.0 | 写>60 / 读>100 MB/s | 未测 | — |

## 结论

- 本机 5G 实测约为文章基线的 **1/3**，与"2×2 + 40MHz（相对 4×4 + 80MHz）"的带宽/流数差异基本吻合
- 若链 3/4 修复，5G 有望接近 4×4 80MHz 的 ~860 Mbps
- 在链 3/4 不修的前提下，可考虑将 5G 带宽提到 80MHz（2×2 80MHz 理论 866 Mbps，实测预计 500~600 Mbps）
